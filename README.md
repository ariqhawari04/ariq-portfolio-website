## 📖 Why I Built This

For a long time, my portfolio lived in a static PDF and a deck of PowerPoint slides. While the data and insights were all there, the format felt outdated and didn't really do justice to the projects I was working on.

I built this custom single-page web portfolio as a modern upgrade. 

I wanted to move away from static slides and create a clean, user-friendly experience. To me, a big part of being a Data Analyst isn't just running statistical models or writing SQL—it's about how those insights are packaged and presented to stakeholders. This site was designed to reflect that mindset:
1. **Frictionless Experience:** Moving from hard-to-read PDFs to a responsive, easy-to-navigate web dashboard.
2. **Business Context First:** Leading with the business dilemma and strategic outcomes before diving into the technical methodology.
3. **Curated Insights:** Filtering out the noise so hiring managers can immediately see the value of the analysis.
